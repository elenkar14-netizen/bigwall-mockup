# Бигвол — мокап мобильной главной

Кликабельный мокап по итогам UX-аудита сайта bigwallsport.ru (октябрь 2026).

| Файл | Экран |
| --- | --- |
| `index.html` | Главная: переключатель «Я впервые / Уже лазаю», бесплатное пробное, абонементы, залы, FAQ |
| `booking.html` | Запись на занятие: формат → зал → контакты |
| `checkout.html` | Покупка: одна короткая форма для всех товаров |
| `dc-lite.js` | Небольшой скрипт, который оживляет экраны (вкладки, FAQ, выбор товара) |

## Как посмотреть

Откройте `index.html` в браузере. На компьютере экран показан в рамке телефона 390×844, на телефоне — на весь экран.

Чтобы получить ссылку для команды: Settings → Pages → Deploy from a branch → `main` / root.

## Что учесть

- Экран записи собирает заявку. По рекомендации № 1 аудита его нужно заменить выбором слота из расписания 1С.
- В квадратных скобках — данные, которых нет на сайте: часы и метро залов, фото.
- Цены и условия взяты с bigwallsport.ru на 21.10.2026.
